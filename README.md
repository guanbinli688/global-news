# 世界观察 · 国际综合新闻站 v1

版本日期：2026-09-10。文件包性质：编辑标准、70个候选来源条目、网站配置与Codex开发任务。

**这不是已运行的采集服务，不代表所有来源已连通，更没有在你的GitHub账号创建或部署网站。**

## 使用方法

将本包解压到你的工作目录，会得到 `global-news-v1` 文件夹。用VS Code打开它，启动Codex，输入：

> 阅读 CODEX_TASK.md，先完成来源诊断和最小可运行预览；不改其他项目，不启用付费服务或上传浏览器凭据。

如果你在父目录的Codex会话中工作，则输入：

> 阅读 global-news-v1/CODEX_TASK.md，只在 global-news-v1 内实现；先诊断来源再搭预览，暂不付费或发布。

## 文件

- `EDITORIAL_SPEC.md`：范围、八个栏目、证据与更正规则、深度标准。
- `config/sources.yaml`：70个候选来源条目及可选社媒层；同一机构不同栏目不算独立证据。
- `config/site.yaml`：15个领域、10个地区、语言阶段、时间窗口、排序、定时建议与安全边界。
- `schemas/event.schema.json`：事件与逐条主张的来源结构；schema本身不能证明新闻真实。
- `CODEX_TASK.md`：开发顺序、验收与禁止事项。
- `SOURCE_NOTES.md`：官方依据和本次核验限制。

## 当前进度边界

已完成：公开 RSS/API 采集与重试、严格 24 小时过滤、事件聚类去重、独立来源/一手资料证据闸门、逐条主张引用、地区与领域覆盖检查、结构化 AI 分析适配器、预算预检、历史归档、上一版保留、过期提示、失败 Issue 告警，以及 GitHub Actions → Pages 工作流。

当前仍未发布。生产源中仅 Agência Brasil（须署名）和 USGS 公共数据已按官方条款放行，其余来源只能发现和交叉核验线索。AI 模型、当日价格、美元预算、GitHub 仓库与 Pages 设置尚待首次配置和用户确认；因此本地 `site/` 仍明确标为开发预览，不冒充生产新闻。

首次配置、Secrets/Variables 和上传范围见 `DEPLOYMENT_CHECKLIST.md`。

## 两个关键区别

1. 这是你的网站配置规范，不是 last30days 自带配置格式；Codex须实现读取它的采集与发布程序。
2. 本地Firefox的X登录与本地last30days配置不会自动进入GitHub Actions。云端只用经确认的接口或脱敏结果，不搬运浏览器Cookie。

## 费用和发布

优先验证公开、可合规使用的接口。模型、预算、付费新闻服务尚未选择，不能擅自调用付费服务。
公开网站只发布允许公开的自写摘要、来源链接和时间；不把全文资料库或私密日志推入公开仓库。
GitHub Pages并不因为源仓库私有就当然成为私人网站，发布前核对实际访问范围。
