# 世界观察 · 国际综合新闻站 v1

版本日期：2026-09-11。项目包含编辑标准、78 个候选来源条目、真实采集/分析管线、静态网站与云端工作流。

**当前只完成过人工触发的生产发布；每日定时仍关闭。来源目录不等于全部获准进入正文，只有许可与证据闸门都通过的事件才能发布。**

## 使用方法

将本包解压到你的工作目录，会得到 `global-news-v1` 文件夹。用VS Code打开它，启动Codex，输入：

> 阅读 CODEX_TASK.md，先完成来源诊断和最小可运行预览；不改其他项目，不启用付费服务或上传浏览器凭据。

如果你在父目录的Codex会话中工作，则输入：

> 阅读 global-news-v1/CODEX_TASK.md，只在 global-news-v1 内实现；先诊断来源再搭预览，暂不付费或发布。

## 文件

- `EDITORIAL_SPEC.md`：范围、八个栏目、证据与更正规则、深度标准。
- `config/sources.yaml`：78 个候选来源条目及可选社媒层；同一机构不同栏目不算独立证据。
- `config/site.yaml`：15个领域、10个地区、语言阶段、时间窗口、排序、定时建议与安全边界。
- `schemas/event.schema.json`：事件与逐条主张的来源结构；schema本身不能证明新闻真实。
- `CODEX_TASK.md`：开发顺序、验收与禁止事项。
- `SOURCE_NOTES.md`：官方依据和本次核验限制。

## 当前进度边界

已完成：公开 RSS/API 采集与重试、严格 24 小时过滤、事件聚类去重、独立来源/一手资料证据闸门、逐条主张引用、地区与领域覆盖检查、结构化 AI 分析适配器、预算预检、历史归档、上一版保留、过期提示、失败 Issue 告警，以及 GitHub Actions → Pages 工作流。

首次生产版已发布至 https://guanbinli688.github.io/global-news/ 。复盘发现旧版虽抓到 190 个候选，但正文权利审核仅放行 Agência Brasil、NASA 和 USGS，最终又受证据与 AI 队列限制，只发布 5 条，其中 3 条是地震；这不是来源抓取数量不足，而是来源结构和发布门槛不合格。

修正后，正文许可白名单扩展为 11 个来源：Agência Brasil、NASA、USGS、美国司法部、FDA、NIH、GOV.UK、European Commission、Horizon Magazine、Global Voices 与 NIST。最后一次免费联网验收抓到 222 个 24 小时候选、聚为 208 个事件、44 个通过证据门槛，并选出 11 个分析候选。发布门槛同时提高为至少 10 条、5 个来源组、4 个栏目、4 个地区和 6 个主题；灾害类最多 2 条，任一项不足就保留上一版而不发布。无模型时仅 USGS 公共数据可确定性成稿，因此免费验收只生成 2 条且被正确阻断，不能把它误当成最终新闻数量。

首次发布后 `ENABLE_AI_ANALYSIS`、`ENABLE_PUBLISH` 与 `ENABLE_SCHEDULED_PUBLISH` 已重新关闭；现有 Pages 保持在线，后续采集不会自动运行。扩源修正版在再次付费分析与覆盖公开页面前仍需人工确认。

首次配置、Secrets/Variables 和上传范围见 `DEPLOYMENT_CHECKLIST.md`。

## 两个关键区别

1. 这是你的网站配置规范，不是 last30days 自带配置格式；Codex须实现读取它的采集与发布程序。
2. 本地Firefox的X登录与本地last30days配置不会自动进入GitHub Actions。云端只用经确认的接口或脱敏结果，不搬运浏览器Cookie。

## 费用和发布

优先验证公开、可合规使用的接口。当前已配置 OpenAI 模型与硬预算，但三个运行开关均关闭；再次调用付费模型或覆盖公开页面前必须确认。
公开网站只发布允许公开的自写摘要、来源链接和时间；不把全文资料库或私密日志推入公开仓库。
GitHub Pages并不因为源仓库私有就当然成为私人网站，发布前核对实际访问范围。
